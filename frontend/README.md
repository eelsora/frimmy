# Frimmy Frontend

냉장고 재료 기반 AI 레시피 추천 서비스의 모바일 앱

## Tech Stack

| | Stack | Version |
|---|---|---|
| **Framework** | React Native (Expo) | Expo 56 / RN 0.85 |
| **Language** | TypeScript | 5 |

## Getting Started

### Prerequisites

- Node.js 20+ (LTS)
- Xcode (iOS 개발 시)

### 실행

```bash
npm install
npm run start      # Expo Dev Server
npm run ios        # iOS 시뮬레이터
npm run android    # Android 에뮬레이터
```

### 빌드

```bash
npx eas build --platform ios
npx eas build --platform android
```
